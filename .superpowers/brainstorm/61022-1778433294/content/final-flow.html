2. User Paths

📖 Add a Book
→ Smooth scroll to AddBookIsland
→ User adds book (scan/manual)
→ Book appears on shelf
→ Stats bar updates (1 to lend...)
→ At 3 books: prompt to go public
🔍 Explore Nearby
→ Navigate to /explore
→ If users nearby: blended discovery
→ If zero users: share prompt
(explore page = future design)

Implementation Scope

This spec covers:
  • EmptyShelfIsland component (the empty state with two paths)
  • Integration with /shelf page (conditional render)
  • Scroll-to-AddBookIsland behavior
  • Link to /explore page
Note: The /explore page itself (discovery view, share fallback) is a separate spec.
